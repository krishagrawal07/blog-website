# Inkline Blog Platform

A small full-stack blog platform with user registration, login, post management, comments, REST APIs, and JSON-file persistence.

## Features

- Register, log in, and log out
- Create, edit, and delete posts
- Add and delete comments
- Search published posts
- REST API backend with persistent local storage

## Run Locally

```bash
npm start
```

The app runs at `http://localhost:3000` by default. You can set `PORT` to use another port.

## Test

```bash
npm test
```

On Windows PowerShell, use `npm.cmd test` if script execution policy blocks `npm`.
